# 沖繩旅行手帖

2026/11/6～11/10 五天四夜手機旅行手帖。五天各自一頁，另有行前準備清單。

- `index.html`：11/6 抵達那霸。
- `day-2.html`：11/7 南部、美國村（租車）。
- `day-3.html`：11/8 首里、中部西海岸。
- `day-4.html`：11/9 北部（要還車）。
- `day-5.html`：11/10 返台。
- `prepare.html`：可勾選並儲存在瀏覽器的行前清單。

以純 HTML、CSS、JavaScript 製作，無須安裝套件或建置。GitHub Pages 請選擇 main 分支的根目錄發布。

所有景點、餐廳與飯店位置均使用原行程的 Google Maps 連結。未安排 RYUKYU BEACH CLUB。時間、活動與營業資訊沿用規劃稿，出發前仍須確認。

第一次連線開啟網站後，背景會快取六個頁面，供離線讀取；Google Maps 等外部連結仍需要網路。清單只儲存在同一瀏覽器，不跨裝置同步。

行前證件說明參考 [日本台灣交流協會](https://www.koryu.or.jp/tw/faq/tabid1185.html)：持臺灣駕照赴日駕車，請攜帶護照、駕照正本與日文譯本，臺灣的國際駕照無法在日本使用。
