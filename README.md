# 沖繩旅行手帖

2026/11/6～11/10 五天四夜手機旅行手帖。五天各自一頁，另有行前準備清單。

- `index.html`：11/6 抵達那霸。
- `day-2.html`：11/7 南部、美國村（租車）。
- `day-3.html`：11/8 首里、中部西海岸。
- `day-4.html`：11/9 北部（要還車）。
- `day-5.html`：11/10 返台。
- `prepare.html`：可勾選並儲存在瀏覽器的行前清單。

以純 HTML、CSS、JavaScript 製作，無須安裝套件或建置。GitHub Pages 請選擇 main 分支的根目錄發布。

所有景點、餐廳與飯店均附 Google Maps 連結。11/10 只安排飯店至機場的返程交通，回程班機已確認為 08:15 起飛。

2026/11/3 更新餐飲與動線：T0／T1 依使用者提供的影片分類，T1 只保留 Ocean Boo! 阿古豬涮涮鍋；HUU’S COFFEE 與 Egg me time. 為候補。餐廳、租車門市與計程車均未代訂；公開營業時間不代表已確認特定日期無臨休。
